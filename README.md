# Portal Transparansi Warisan & Asset Pusaka Keluarga

Portal web privat untuk transparansi pengelolaan aset dan harta pusaka keluarga di bawah pengawasan Notaris.

## Cara Menjalankan Melalui Laragon 5
1. Pastikan aplikasi **Laragon 5** sudah dinyalakan dan layanan Apache berjalan (*Start All*).
2. Letakkan folder proyek ini ke dalam direktori `C:\laragon\www\pemweb-obe`.
3. Buka browser lalu akses tautan: `http://localhost/pemweb-obe/`.

## Catatan Fitur Selesai
- Struktur HTML5 semantik (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Hierarki *heading* logis dari `h1` hingga `h3`.
- Atribut *alt text* gambar (informatif, dekoratif, dan *link*).
- Formulir dengan elemen `<label>` yang terikat secara akurat.
- Pengujian aksesibilitas navigasi menggunakan tombol `Tab`.
- Penerapan manajemen *branching* dan *commit* Git secara bertahap.
