# Portal Warisan Keluarga (Family Heritage Portal)

Sistem informasi berbasis web yang dirancang untuk mengelola inventaris harta pusaka, manajemen pengguna, serta alur distribusi aset keluarga secara transparan dan terstruktur. Proyek ini dikembangkan untuk memenuhi penugasan praktikum Mata Kuliah Pemrograman Web (Modul 10 - OBE).

## 📌 Fitur Utama
* **Manajemen Pengguna (`users`):** Pengelolaan data aktor dan hak akses dalam sistem keluarga.
* **Inventaris Aset (`aset`):** Pencatatan data harta pusaka, kategori, kondisi, serta lokasi penyimpanan.
* **Distribusi Aset (`distribusi_aset`):** Modul transaksional alur penyerahan harta warisan yang terhubung dengan *Foreign Key* dan aturan *cascade*.
* **Keamanan Data:** Implementasi koneksi basis data menggunakan PHP Data Objects (**PDO**) dan pencegahan celah *SQL Injection* melalui *Prepared Statements*.

## 🛠️ Teknologi yang Digunakan
* **Bahasa Pemrograman:** PHP, HTML, CSS, JavaScript
* **Basis Data:** MySQL / MariaDB (Dikelola via MySQL Workbench & Laragon)
* **Kontrol Versi:** Git & GitHub
